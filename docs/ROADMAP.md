# Roadmap

Godfather gives ASU students free compute on pods that the AI Society at ASU pays for. This repo holds the CLI and the pod image. Platform's `godfather` module creates, shares and schedules the pods.

Work is tracked in GitHub issues: the master issue [#62](https://github.com/theaisocietyasu/godfather/issues/62) here, and [asusoda/platform#451](https://github.com/asusoda/platform/issues/451) for Platform.

## Next

- Pod security: private workspaces and homes, no sudo, an image version that Platform checks.
- Sign-in in the browser with no copy and paste.
- A permanent domain for the AIS server as the CLI default.
- Release 2.2.0.

## Later

- Upcoming sessions of a pod in the CLI.
- One pod for each member, if that option is chosen.

## Out of scope

- Pod management in the CLI. Officers use the Platform dashboard.
