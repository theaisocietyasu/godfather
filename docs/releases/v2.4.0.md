Godfather 2.4.0 opens web apps on a pod in your browser and sets up member folders.

Changes
- `godfather connect <pod-id> --forward 8080` forwards http://localhost:8080 on your laptop to port 8080 on the pod, for a llama.cpp chat UI, Jupyter or any server bound to `127.0.0.1` on the pod. `--forward 9000:8081` uses a different local port. Repeat the option for more ports.
- Pod image 2.4.0: member setup. Officers give a pod a public repo URL and a setup script on the Platform dashboard (New pod or Member setup in the pod menu). Each member gets the repo cloned and the script run in their folder on their next connection, and again after a change. Output goes to `~/godfather-setup.log`. Off unless set.
- Pod image 2.4.1: a member shell with a terminal has job control (Ctrl-Z, `bg`, `fg`). A failed clone says that the repo must be public.

Upgrade steps
- Members run `pip install -U godfather-cli`.
- Officers recreate pods on `ghcr.io/theaisocietyasu/godfather-base:latest` for member setup and job control.
