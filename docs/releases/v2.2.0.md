Godfather 2.2.0 signs you in through the browser and makes each member's files on a pod private.

Changes
- `godfather auth` signs in through the browser. After the Discord sign-in, the browser hands the login back to the CLI, so you do not paste a token. If that is not possible (no browser on this computer, an older server, or no sign-in in 5 minutes), the CLI asks for the token as before. `godfather auth --paste` goes straight to the paste step.
- `godfather sessions` lists the upcoming sessions on your pods in local time. When none of your pods is running, `godfather connect` shows the next session.
- `godfather connect --admin` asks for a root shell. Officers get it only on a pod whose owner turned on pod admin.
- Pod image 2.2.0: your workspace and home folder are private to you, new files are private (umask 077), other members cannot list `/workspace/users`, the image has no sudo, and members cannot open port forwards. Banners show the image version.
- Python 3.8 to 3.13 are tested on every change.

Upgrade steps
- Members run `pip install -U godfather-cli`. The saved login still works. Run `godfather auth` only if the CLI asks.
- Files in `/workspace/shared` stay readable. Other files are private. To share a file, copy it to `/workspace/shared` and run `chmod o+r` on it.
- Officers recreate each pod on the new image after the announced time.
