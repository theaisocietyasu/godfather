Godfather 2.1.0 makes the CLI menus interactive and shows more detail about pods, login and errors.

Changes
- `godfather` with no arguments opens an arrow-key menu: Connect to a pod, List pods, Status, Log out (or Log in), Exit. Enter chooses. Ctrl-C quits.
- The pod picker uses the arrow keys and shows each pod's name, status, access (public or shared with you) and pod ID. A pod that is not running shows with the reason and cannot be chosen. With only one pod to connect to, the CLI asks for a yes instead.
- `godfather list` shows the full pod ID and the command to connect to it.
- `godfather status` shows the server, org, login state, the saved token, about when the token expires, the number of pods you can use, and whether a newer CLI is on PyPI.
- Errors say what to do next: server not reachable, token expired (the CLI offers to log in again), pod not running, pod not shared with you, and no pods.
- A spinner shows during each server call.
- When input is not a terminal, the CLI keeps the numbered prompts. All commands and flags work as before.
- New dependency: `questionary`.

Upgrade steps
- Members run `pip install -U godfather-cli`. The saved login still works.
