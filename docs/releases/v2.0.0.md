Godfather 2.0.0 moves pod management to the AI Society platform. The CLI now signs in and connects through the platform's compute module. The old backend and portal are removed.

Changes
- `godfather auth` opens the platform sign-in page for the org (`/api/compute/<org>/cli/login`), and the member pastes the token it shows. Tokens start with `plat_` and last 90 days.
- `godfather list` and `godfather connect` use `/api/compute/<org>/me/pods`.
- New `--org` flag and `GODFATHER_ORG` env var. The default org is `ais`. The server and org from the last login are remembered.
- Removed `backend/`, `frontend/`, `nginx/`, `docker-compose.yml`, `DEPLOYMENT.md`, and their CI and image workflows. They remain in the history up to v1.1.0.

Upgrade steps
- Members run `pip install -U godfather-cli` and then `godfather auth`. Tokens from 1.x no longer work.
- Officers move pods to the platform: create them under Compute in the platform web app, then terminate the old ones.
